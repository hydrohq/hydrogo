# ADR-0328: Pure Go branded quote PDF rendering

- **Status:** Accepted
- **Date:** 2026-09-29
- **Supersedes:** None
- **Superseded by:** None

## Context

Client Editions may need branded quotes and pro forma documents without a
browser, system PDF binary, or C library. The first implementation should be a
bounded reusable renderer and must not activate a route, worker, or migration
by itself.

## Decision

`modules/documents` exposes a typed quote input, exact minor-unit money
calculation, and a PDF byte renderer. Rendering uses the Pure Go
`github.com/signintech/gopdf` library and the Go font embedded by
`golang.org/x/image`; an Edition may provide its own bounded TrueType font and
PNG/JPEG logo. Logo dimensions, font bytes, line count, text, and PDF output
are bounded. Quotes retain no data in HydroGo.

The first slice does not add quote persistence, sales routes, or automatic
email attachment because HydroGo has no sales/document workflow to integrate.
The resulting bytes are suitable for a caller-owned download or message
attachment once that workflow exists.

## Alternatives

- HTML-to-PDF via a browser or command-line tool: rejected due to an external
  runtime requirement.
- Hand-written PDF serialization: rejected because fonts, images, object tables,
  and page layout are easy to get wrong.
- Store quotes in Core tables: rejected until a generic sales workflow exists.

## Consequences

### Benefits

- Compact deployments add no worker, route, migration, or external runtime.
- Decimal amounts are calculated from integer minor units with checked
  overflow and explicit tax rounding.

### Costs and risks

- A caller must own persistence, authorization, download policy, and mail
  delivery.
- Complex Unicode requires a TrueType font with the needed glyph coverage.
- PDF generation is synchronous and caller input/output limits are fixed.

## Scale impact

- Compact: opt-in call only; output is capped at 8 MiB.
- Standard: caller controls concurrency and request deadlines.
- Distributed: documents are generated by the calling instance and may be
  stored in the Edition's existing blob store.

## Database impact

- SQLite: none.
- PostgreSQL: none.
- Future adapters: none.

## Cache impact

No cache. Quotes contain customer-specific data and should be treated as
private by any caller that serves or stores them.

## Deployment and compatibility

No migration or runtime process is introduced. The new Go dependency is pinned
in `go.mod`; production remains self-contained and does not execute an external
renderer.

## Validation

Unit tests cover tax calculation, overflow, Unicode PDF generation, and output
bounds. `CGO_ENABLED=0 go test ./modules/documents` proves no C runtime is
required by this package.
