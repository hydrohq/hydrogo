# R56 — S3/CDN configuration wiring

**Date:** 2026-09-17  
**Status:** Successful (local contract + runtime wiring)

Media configuration now wires `cdn_base_url` and `s3_force_path_style` into the
runtime `S3BlobStore`. Previously `cdn_base_url` was validated but dropped when
the store was constructed, so configured public/CDN URLs could never be
generated by the running binary.

Environment variables:

- `HYDRO_MEDIA_CDN_BASE_URL` — credential-free HTTP(S) base with optional path
  prefix; query/fragment/userinfo are rejected.
- `HYDRO_MEDIA_S3_FORCE_PATH_STYLE` — boolean for MinIO/S3-compatible endpoint
  addressing.

Validation covers config loading and the `cmd/hydro` wiring path. Real provider
IAM, CDN purge, retention and failover remain deployment gates.
