# R3 SMTP notifier adapter doğrulaması

**Tarih:** 2026-09-09  
**Roadmap:** R3 güvenlik / production notifier  
**Durum:** Adapter ve config sınırı başarılı; gerçek sağlayıcı teslimat tatbikatı açık.

`internal/mailer` STARTTLS, optional SMTP AUTH, context deadline, header injection kontrolü ve 1 MiB bounded body ile çalışan bir sender sağlar. `NotificationSender` bu sender'ı password-reset ve invitation notifier sözleşmelerine bağlar; token'lar log/audit'e yazılmaz. `hydro serve` SMTP host config edildiğinde iki notifier'ı otomatik bağlar, host yoksa yerel kurulumda bu route'ları etkinleştirmez.

SMTP ayarları `mail.host`, `mail.port`, `mail.from`, `mail.username`, `mail.password`, `mail.starttls` veya `HYDRO_SMTP_*` environment değişkenleriyle verilir. Kısmi veya geçersiz ayar config validation aşamasında reddedilir; password tek başına kabul edilmez.

Çalıştırılan kontroller:

```text
go test ./internal/mailer ./internal/config ./cmd/hydro
go vet ./internal/mailer ./internal/config ./cmd/hydro
```

Gerçek SMTP sağlayıcısına teslim, bounce/retry/alerting ve provider credential/key rotation bu raporun kapsamı dışındadır.
