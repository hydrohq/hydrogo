# E0 Browser E2E Validation — 2026-09-21

The isolated local Playwright harness was executed through
`scripts/run-e2e.ps1` with a disposable SQLite database and test-only admin
credentials.

Observed result: 48 passed, 24 intentionally skipped visual/locale cases.
The run covered generated frontend, Admin Studio login, permissions,
operations, developer resources, media upload, page/news flows, auth-negative
journeys, accessibility and responsive bounds.

This is evidence for the existing browser harness, not completion of ADR-0195:
the current fixture does not provision a signed external admin extension, so
cross-origin iframe `MessageChannel` bind/revoke remains an explicit gate.
