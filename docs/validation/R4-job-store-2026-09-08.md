# R4 kalıcı job lease store doğrulaması

**Tarih:** 2026-09-08  
**Roadmap:** R4 ortak transaction/hook/event/job contract kiti  
**Durum:** SQLite/PostgreSQL lease backend'i, News durable queue adapter'ı ve dialect-free bounded hook fixture'ı başarılı; production worker bootstrap wiring'i açık.

`internal/jobs/sqlstore` SQLite/PostgreSQL placeholder sözleşmesiyle idempotent enqueue, bounded kapasite, token sahiplikli claim/ack/nack ve süresi dolmuş lease reclaim davranışını sağlar. `202609080013_jobs` migration'ı iki dialect için aynı şema ve checksum metadata'sı taşır. News'in mevcut bounded in-process queue'si geriye dönük korunur; kalıcı backend'e geçiş ayrı wiring kararıdır.

Çalıştırılan kontroller:

```text
go test ./internal/jobs/... ./migrations ./...
go vet ./...
```

SQLite contract; duplicate payload conflict, yanlış worker reddi, nack sonrası reclaim ve ack sonrası silmeyi doğrular. PostgreSQL servis matrisi CI'da migration ve mevcut contract testleriyle ayrıca çalışır; bu store için gerçek PostgreSQL lease testi henüz açık kapıdır.

`HYDRO_TEST_POSTGRES_URL` tanımlı CI koşusunda aynı lease senaryosu PostgreSQL üzerinde de çalıştırılır; yerel ortamda değişken yoksa test bilinçli olarak skip edilir. `sqlstore.Queue`, `news.DurableQueue` ile compile-time contract testinde doğrulanır.

`internal/hooks.Dispatcher` iki modülün kullanabileceği ortak event sözleşmesini doğrular: başarılı event ID'leri idempotent biçimde tek kez işlenir, başarısız handler yeniden denenebilir ve dedup penceresi bounded tutulur.
