# R3 SMTP notifier adapter validation

**Date:** 2026-09-09  
**Roadmap:** R3 security / production notifier  
**Status:** Adapter and config boundary succeeded; actual provider delivery drill remains open.

`internal/mailer` provides a sender that works with STARTTLS, optional SMTP AUTH, context deadline, header injection control, and a bounded 1 MiB body. `RetrySender` implements a provider retry policy with bounded exponential backoff and context cancellation; permanent provider errors can be halted via `ShouldRetry`. `NotificationSender` binds this sender to the password-reset and invitation notifier contracts; tokens are not written to log/audit, and if the sender is missing, it returns a fail-closed error instead of panicking. `hydro serve` automatically binds the two notifiers when an SMTP host is configured; if there is no host, it does not enable these routes in a local setup.

SMTP settings are provided via `mail.host`, `mail.port`, `mail.from`, `mail.username`, `mail.password`, `mail.starttls`, or `HYDRO_SMTP_*` environment variables. `mail.max_per_second` and `mail.max_per_hour` (or `HYDRO_SMTP_MAX_PER_SECOND` and `HYDRO_SMTP_MAX_PER_HOUR`) bound per-process outbound delivery; defaults are 5 per second and 100 per hour. The token buckets hold send calls until capacity is available and respect caller cancellation. Partial or invalid settings are rejected during the config validation phase; a password alone is not accepted.

Executed checks:

```text
go test ./internal/mailer ./internal/config ./cmd/hydro
go vet ./internal/mailer ./internal/config ./cmd/hydro
```

Delivery to an actual SMTP provider, provider bounce classification/alerting, and credential/key rotation are outside the scope of this report; retry behavior was validated as a local contract.

`internal/security.DistributedLimiter` behaves fail-closed on a shared-store error; it carries the responsibility of store atomic counter and TTL. This contract does not replace Redis or another provider, and multi-instance performance/partition drills remain open.
