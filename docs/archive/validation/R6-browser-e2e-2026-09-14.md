# R6 browser E2E validation — 2026-09-14

`scripts/run-e2e.ps1` completed against an isolated SQLite server with a
test-only administrator account. Chromium executed **30/30 tests** in 7.3s.

The run covered generated public home, newsroom, product, shop, and member
login routes at desktop and 390x844 mobile viewports, accessible-name and
keyboard-focus checks, horizontal-overflow checks, published-content API
reads, admin login, media upload, and the generated developer/operations/
security/permissions/news/pages surfaces.

This is local browser evidence only. It does not certify real PostgreSQL,
cross-origin session mutation, MFA/password reset, external payment callbacks,
or customer-sized capacity. Those gates remain open in
`docs/OPEN_GATES_AND_OPERATOR_ACTIONS.md`.
