# Security Policy

Please do not open a public issue for an undisclosed vulnerability. Report it
through a private GitHub Security Advisory for this repository (Security tab,
"Report a vulnerability"). If private reporting is unavailable, contact the
maintainers privately and include "HydroGo security report" in the subject.

Supported versions, what to include in a report and the disclosure process are
in [docs/SECURITY.md](docs/SECURITY.md).
